# Integrations

Ready-to-use integrations for your self-hosted Shortl instance.

| Folder | What it is | Setup |
|--------|-----------|-------|
| `extension/` | Chrome/Edge/Firefox browser extension | Load unpacked, add site URL + API key |
| `wordpress/` | WordPress plugin (auto-shorten posts, `[shortl]` shortcode) | Upload plugin, Settings → Shortl |
| `zapier/` | Zapier / Make.com recipe using the REST API + webhooks | Generic HTTP app, Bearer API key |

**Chat bots** (Telegram, Slack, Discord) are built in — configure them in
**Admin → Settings → Bots**, then users connect from **Integrations** and
shorten links straight from chat. See the main docs.
