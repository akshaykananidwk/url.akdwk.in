# Shortl Browser Extension (Chrome / Edge / Firefox)

Shorten the current tab's URL with two clicks.

## Install (developer mode)
**Chrome / Edge:** go to `chrome://extensions`, enable *Developer mode*, click
*Load unpacked*, and select this folder.

**Firefox:** go to `about:debugging` → *This Firefox* → *Load Temporary Add-on*
and pick `manifest.json`.

## Setup
Click the toolbar icon → *Settings* → enter your Shortl site URL
(e.g. `https://url.akdwk.in`) and an API key (Developers → API Keys). Done —
open the popup on any page and hit *Shorten*.
