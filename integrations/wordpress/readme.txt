=== Shortl URL Shortener ===

Shorten links with your self-hosted Shortl instance from WordPress.

== Installation ==
1. Zip this folder and upload it under Plugins → Add New → Upload, or copy the
   folder into wp-content/plugins/.
2. Activate "Shortl URL Shortener".
3. Go to Settings → Shortl, enter your Shortl site URL and an API key
   (Developers → API Keys on your Shortl account).
4. Optionally enable "Auto-shorten new posts" — each published post gets a
   short link stored in the "shortl_url" custom field.

Use the [shortl url="https://example.com"] shortcode anywhere to output a short link.
